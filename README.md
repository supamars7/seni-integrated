# Seni Integrated Systems Website

A self-contained, responsive frontend website for **Seni Integrated Systems**, built with semantic HTML, custom CSS, and vanilla JavaScript.

## Included experience

The site includes a sliding hero banner with manual and automatic controls, responsive navigation with a mobile menu, smooth anchor scrolling, animated proof-point counters, service capability cards, an approach section, and a contact CTA wired to the company email address from the supplied reference document.

## Brand direction

The visual system is based on the supplied Seni Integrated Systems letterhead and logo: deep indigo / navy, bright orange accents, warm off-white surfaces, a high-contrast editorial layout, and a combination of Space Grotesk with a restrained serif italic accent.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local static server:

```bash
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.
